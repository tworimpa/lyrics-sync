작업 순서와 주의사항

모바일 시간 기록

시작·종료·Enter·이전/다음 가사를 눌러도 페이지는 자동으로 이동하지 않습니다. 가사 표 내부만 선택 줄을 따라갑니다. 긴 가사는 기록 버튼 위의 가사 영역 안에서 스크롤하세요. 표를 확인할 때는 ‘표 보기’, 돌아올 때는 ‘기록 버튼으로’를 누르세요. 일반 화면 스크롤은 그대로 사용할 수 있습니다.

콘티 · 컷 파일 타임라인

콘티 가져오기에서 MD·JSON·CSV를 선택한 뒤 목록을 확인하고 적용합니다. 원래 컷 시간과 원문을 보존하며 가사 시간은 바꾸지 않습니다. 컷 파일 여러 개 선택 또는 폴더 선택으로 이미지를 연결하세요. 맞닿은 컷 경계는 드래그하거나 숫자로 수정할 수 있습니다. 콘티 모드에서 S/E는 선택한 컷 시작/종료, ↑↓는 컷 선택입니다.

JSON은 파일명을 기억하지만 파일 바이트는 포함하지 않습니다. 같은 원본 폴더를 다시 선택하거나, 파일 포함 저장을 사용하세요. 음원 최대 40 MiB, 사용 중인 컷 파일과 합계 80 MiB 이하만 통합 저장합니다. ZIP은 먼저 압축을 풉니다. 원화/영상 생성과 MP4 렌더링은 하지 않습니다.

새 노래 작업

새 프로젝트 → 음원 선택 → 가사 입력 → 재생하며 S/E 또는 Enter → 미세 보정 → 프로젝트 저장 → SRT 내보내기.

기존 제리 작업 이어하기

원본 제리 편집기에서 저장한 버전 1 JSON을 ‘프로젝트 열기’로 선택하세요. 가사와 시간을 버전 3으로 변환합니다. 그다음 원본 제리 MP3를 선택하세요. 최초 HTML 자체에는 수정한 시간이 들어 있지 않습니다.

가사와 시간 보정

한 줄 문구 변경은 표의 ‘수정’을 사용하세요. 전체 붙여넣기는 반복 가사의 대응 관계를 확신할 수 없으면 시간을 초기화합니다. 전체 가사와 순서가 동일하면 그대로 유지합니다. 변경은 실행 취소로 복원할 수 있습니다.

Enter 연속 기록

선택 줄의 시작을 찍고 다음 줄로 이동합니다. 앞선 줄에 시작만 있다면 종료를 현재 시각으로 채웁니다. 간주 앞에서는 ↑로 이전 줄을 선택한 뒤 E로 실제 종료를 기록하세요. 마지막 줄은 E로 종료를 찍으세요. 시간은 음원 위치 기준으로 기록되므로 배속 재생에서도 같은 타임라인을 사용합니다.

저장과 재연결

기본 JSON에는 음원이 없습니다. JSON과 음원을 각각 선택하거나, 음원 포함 저장의 .lysync 파일을 프로젝트 열기로 불러오세요. 휴대용 HTML은 편집기와 음원·작업을 모두 담으며, 브라우저에서 열면 복원됩니다. 수정 후에는 다시 저장해야 파일에 반영됩니다. 자동 복구는 이 브라우저의 보조 저장이며 영구 보관을 보장하지 않습니다. 동일 위치의 HTML을 계속 사용하고 매 작업 후 JSON을 백업하세요.

음원 변경

음원 파일명·크기·길이·가능한 경우 SHA-256 해시를 비교합니다. 기존 정보와 다르면 확인합니다. 시간이 자동으로 늘어나거나 잘리지 않습니다. 음원 재연결 시 편집 실행 취소 기록은 비워집니다. 새 노래는 반드시 ‘새 프로젝트’에서 시작하세요.

형식과 한계

브라우저가 재생할 수 있는 음원만 지원합니다. 파일 선택란의 확장자가 실제 코덱 지원을 보장하지 않습니다. 최대 음원 120 MiB, 가사 1,000줄, 한 줄 2,000자, 길이 24시간입니다. 40 MiB 또는 20분을 넘는 음원은 메모리 보호를 위해 파형 생성을 건너뜁니다. 파형 실패 시 재생과 수동 기록은 사용할 수 있습니다.

이 버전은 수동 싱크 편집기입니다. 음원 포함 저장·가사 분할/병합·자막 가져오기·영상 큐를 지원합니다. 자동 음성 인식·보컬 종료 분석·영상/이미지 생성·단어별 노래방 자막은 제공하지 않습니다. 선택 줄 반복은 앞 0.7초, 뒤 0.4초를 포함하며 정밀한 오디오 루프 편집기는 아닙니다. SRT/WebVTT는 모든 시간을 입력하고 오류를 수정한 뒤 내보냅니다. CSV는 미입력 상태도 저장합니다.

영상 큐와 편집

가사 연결 큐는 선택한 가사들의 가장 이른 시작부터 가장 늦은 종료까지를 사용합니다. 가사 분할/병합 시 연결 ID를 갱신합니다. 가사를 삭제하거나 자막으로 교체하면 연결을 직접 확인하세요. 직접 지정 큐는 가사 시간 일괄 이동의 영향을 받지 않습니다. 큐 JSON/Markdown은 현재 시간의 스냅샷이며, 다시 이어 할 때는 프로젝트 JSON 또는 .lysync가 필요합니다.

자막 가져오기

SRT/WebVTT의 텍스트와 시간을 가져옵니다. 스타일·위치·주석은 제외하며 알림을 표시합니다. 여러 줄 자막은 유지합니다. 줄 단위 LRC의 종료는 다음 타임스탬프로 추정하므로 마지막 종료와 간주를 직접 보정하세요. LRC 내보내기는 밀리초 표기와 빈 종료 타임스탬프를 사용합니다. 플레이어에 따라 지원 차이가 있을 수 있습니다.

음원 포함 저장

.lysync / HTML에는 원본 음원이 포함됩니다. 공유할 때 공개 범위를 확인하세요. 메모리 보호를 위해 내장 음원은 40 MiB 이하입니다. 음원과 가사를 서버로 전송하지 않고 외부 스크립트도 사용하지 않습니다.
